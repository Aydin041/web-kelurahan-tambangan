Pengembangan Website Portal Digital Kelurahan Tambangan, Kec. Mijen, Kota Semarang

1. Rancangan Database (Entity Relationship Diagram / ERD)

Berikut struktur tabel inti yang akan digunakan saat website masuk ke tahap produksi (database nyata):

USERS (Manajemen Akun & 4 Role)
id (PK), name, email, password_hash, role (super_admin | admin | kontributor), status, created_at
UMKM & UMKM_PRODUCTS
UMKM: id (PK), name, category, owner, phone, address, maps_url, hours, image, desc
PRODUCTS: id (PK), umkm_id (FK), name, price, desc
NEWS & ANNOUNCEMENTS
NEWS: id (PK), title, category, excerpt, content, image, status, author_id (FK)
ANNOUNCEMENTS: id (PK), title, category, priority, details
AGENDAS, GALLERY & ASPIRATIONS
AGENDAS: id (PK), title, category, date, time, location, organizer
GALLERY: id (PK), title, tag, image
ASPIRATIONS: id (PK), sender_name, rw_area, category, message
